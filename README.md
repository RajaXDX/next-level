# بوابة رجا

الصفحة الرئيسية التي تجمع الألعاب والمشاريع: <https://rajaxdx.github.io>

HTML/CSS/JS خام بلا مكتبات ولا أدوات بناء — نفس أسلوب بقية المشاريع.

## البنية

```
index.html              الصفحة كاملة + لوحة الإدارة
css/style.css           التنسيق (خضرة نجدية + ذهب، RTL)
js/config.js            مفاتيح Supabase + النسخة الاحتياطية للمشاريع
js/app.js               جلب المشاريع وعرضها
js/admin.js             لوحة الإدارة + توليد الوصف بالذكاء الاصطناعي
assets/                 شعارات المشاريع
supabase-projects.sql   جدول `projects` وسياساته
```

## الإعداد

1. شغّل `supabase-projects.sql` على **نفس مشروع Supabase** الذي تستعمله
   تحدي رجا (`rqcltlleqpppeywxbkpo`) — حساب الإدارة ودالة `is_admin()`
   موجودان هناك، فلا حاجة لمشروع ثانٍ ولا لحساب ثانٍ.
2. افتح الموقع → ⚙️ الإدارة → ادخل بحساب الإدارة نفسه.
3. لتوليد الأوصاف: افتح «مفتاح Claude API» في أسفل اللوحة والصق مفتاحك.

## أشياء تُعرف قبل التعديل

1. **البطاقات ظاهرة افتراضياً في CSS، والإخفاء يُضاف بجافاسكربت.**
   العكس (تبدأ شفافة ثم يُظهرها `IntersectionObserver`) يجعل أي تعثّر في
   المراقب يترك البوابة **بيضاء تماماً** — وقع فعلاً أثناء الاختبار.
   ومعه مؤقّت أمان 1.5 ثانية يكشف ما بقي. الزينة ليست شرطاً لظهور المحتوى.

2. **`FALLBACK_PROJECTS` في `config.js` ليست زينة.** بدونها تصير البوابة
   صفحة فارغة لحظة تعطّل Supabase — وهي الصفحة التي تعطي رابطها للناس.
   إذا عدّلت مشروعاً في قاعدة البيانات، عدّله هنا أيضاً.

3. **مفتاح Claude API يُحفظ في `localStorage` على جهازك وحده** ولا يدخل
   المستودع. لهذا زر «اكتب الوصف» يشتغل من جهازك فقط — وهذا مقصود:
   مفتاح داخل صفحة منشورة يقرأه أي زائر ويستنزف رصيدك.
   النداء كله خلف `generateDescription()` في `admin.js`، فنقله لاحقاً
   إلى Supabase Edge Function تغييرٌ محصور في دالة واحدة.

4. **`status = 'hidden'` مفروض في سياسة القراءة لا في الكود.** لو كان في
   الكود وحده لصار إخفاءً بصرياً يكشفه أي أحد من أدوات المطوّر.

5. **كل نص من قاعدة البيانات يمرّ بـ`esc()` وكل رابط بـ`safeUrl()`**
   قبل أن يدخل `innerHTML`/`href`. الحقول تكتبها أنت — والمصدر ليس ضماناً.

6. **ارفع `?v=` في `index.html`** بعد أي تعديل على CSS/JS وإلا بقي الكاش.

## ما تم التحقق منه (2026-08-04)

- المشروعان يظهران بلونيهما وشعاريهما، والروابط تفتح في تبويب جديد
- النسخة الاحتياطية تعمل: الجدول غير موجود بعد → البوابة كاملة بلا خطأ
- التهريب: اسم فيه `<img onerror>` يُعرض نصاً ولا يُنفَّذ
- `javascript:` في حقل الرابط يصير `#`
- نداء الذكاء الاصطناعي: الترويسات والنموذج والجسم صحيحة (باعتراض `fetch`)
- رفض السلامة يُلتقط قبل قراءة `content` فلا ينهار الزر
- الجوال 375px: عمود واحد، بلا تمرير أفقي، وكل عناصر اللمس ≥ 44px
